NEXGENMARKETING - VERSION CON BACKEND

1) Subir esta carpeta a Netlify.
2) En Supabase > SQL Editor ejecutar supabase-schema.sql.
3) En Netlify > Environment variables deben existir:
   SUPABASE_URL
   SUPABASE_PUBLISHABLE_KEY
   MERCADOPAGO_ACCESS_TOKEN

4) Para el backend REAL de administración agregar además:
   SUPABASE_SECRET_KEY = Secret key de Supabase (NO compartir)
   ADMIN_SESSION_SECRET = una cadena aleatoria larga (recomendado). Si no se configura, el backend usa la clave predeterminada incluida en las funciones.
   PUBLIC_SITE_URL = https://nexgennmarketing.netlify.app

5) Mercado Pago: configurar webhook hacia:
   https://nexgennmarketing.netlify.app/api/mp-webhook
   Activar los eventos de Suscripciones: subscription_preapproval y subscription_authorized_payment.

6) Importante: el Access Token de Mercado Pago y la Secret Key de Supabase son privados. Nunca ponerlos dentro de index.html.

7) El QR sigue siendo visual y ampliable. El flujo de suscripción usa Checkout de Mercado Pago desde los botones de los planes.
